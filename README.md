# FiStar

フィルムスキャンTIFFを用いた2Dスターショットの半自動解析アプリです。ガントリ・コリメータ・カウチを1画像につき1軸ずつ評価します。

**施設内QAの補助ツールです。実画像での臨床的精度は未検証です。** 自動検出した照射帯・レーザー位置・校正値を操作者が確認し、施設手順により最終判断してください。

## 起動

Python 3.11以上と、日本語を表示できるフォントが必要です。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m fistar
```

WindowsのPython環境では `.venv\Scripts\activate` で環境を有効にします。単独実行ファイルの配布は含みません。

## 解析の手順

**画像を開く → 右クリックでレーザー点を指定 → 照射帯を検出 → 画像と結果を確認して保存**の流れです。段階ごとの確認ボタンはありません。

1. ウィンドウ上部左のファイル指定用のテキスト欄へTIFF画像パスを入力し「開く」を押します。Enterでも開けます。「参照」でファイルを選ぶと、そのまま読み込みます。解析は輝度固定（0.299R + 0.587G + 0.114B）、表示は自動調整です。原画・元の16bit画素は保持します。
2. 装置名は必要なら入力します。空欄はtempです。回転軸は前回の選択を次回起動にも引き継ぎます。
3. 解像度設定は画像下のツールアイコンの右側にあり、初期値は「未校正」（px）です。「TIFFタグ」は画像のX/Y解像度を利用し、「入力値」はテキスト欄に1pxあたりの長さをmm/pxで入力します。入力値はX/Y共通です。正の有限値が必要で、未入力・無効値の場合は入力完了まで検出と保存を許可しません。
4. 画像上の穴などを右クリックしてレーザー基準点を指定します。専用の段階フレームはありません。左ドラッグは常に画像移動です。2点校正を行う間だけ左クリックで校正点を指定します。
5. 「照射帯を検出」を押します。暗い帯固定で検出し、結果をすぐ表示します。反対向きの腕を合わせて1本の帯として数えます。必要なら一覧のチェックで除外します。線の手動移動・回転・追加はありません。
6. 結果欄の画像名・装置・軸・校正・レーザー位置・帯本数・評価値と、拡大画像の検出線や交点を確認し「結果を確認して保存」を押します。初期方式は交点重心、最小円方式への切替も可能です。

レーザー位置、探索円の半径、最小ピーク高さを変更すると「再検出が必要」と表示し、再検出まで保存を止めます。校正、装置、軸、方式、帯の除外変更は結果へ反映します。検出条件は最初から表示し、必要に応じて調整します。古い状態の非同期検出結果を新しい状態へ適用しません。

### 画像の操作と検出調整

- 通常は左ドラッグで画像を移動します。上スクロールで拡大、下スクロールで縮小します。ズームの基準はカーソル位置ではなく、現在の表示中心です。全体表示中でもドラッグで移動できます。
- 画像下のツールはFiRecの手・リセット・定規アイコンです。手はドラッグ移動・スクロール拡大縮小、リセットは画像全体表示です。定規は2点の左クリックで距離を測定します。未校正ならpx、校正済みならpxとmmを表示します。ダブルクリックでも画像全体を表示できます。
- 明るさとコントラストは読込時に自動調整し、手動の表示下限・上限欄はありません。表示調整は解析値へ影響しません。
- Pylinac **3.48.0** の `StarProfile` を使い、レーザー点を中心とする円周プロファイルから各腕の半値幅中心を検出します。円周順に並べ、半周分離れた点同士を結びます。線をレーザー点に強制的に通しません。
- 探索円の半径は、レーザー点から最も近い画像端までの距離に対する割合です。初期値は85%、最小ピーク高さ25%、暗い帯固定です。高さは円周プロファイルの相対値です。25%なら最大ピークの1/4以上の高さを候補にします。低くすると弱い帯を拾いやすい一方でノイズも拾いやすくなり、高くするとノイズを除きやすい一方で弱い帯を見落としやすくなります。帯中心を求める半値幅（50%）とは別の設定です。
- 探索円・検出点・中心線・帯番号を確認してください。帯の幅、重なり、ノイズ、探索中心のずれで結果が変わるため、必要に応じて半径・高さを調整してください。自動再探索は行いません。
- 検出点が奇数、6点未満、円周を抽出できない場合は理由を表示します。既存の線を保持し、条件を変更して再検出できます。
- プロファイルは内部計算にのみ使用し、画面には表示しません。

### 番号・点・線の表示

右側の解析設定の下にある「表示する項目」を開くと、レーザー点・探索円・検出点・中心線・帯番号・交点・交点ラベル・推定中心・評価円・偏位線を個別にON/OFFできます。初期状態では交点ラベルだけOFFです。表示項目の枠は初期状態で閉じ、見出しだけを表示します。設定は今回の起動中だけ保持し、解析値や確認状態を変更しません。

帯番号・マーカーは画面上で一定サイズを保ちます。中心は塗りつぶさない輪郭、交点は前面に表示します。交点ラベルと一覧の帯ペアは「1–2」のように表記します。線の手動移動・回転・追加はできません。帯の除外は一覧のチェックで行います。

交点は最小円方式でも表示できます。旧記録に交点情報がない場合は、交点重心方式を明示的に選んで追加計算した後に表示されます。

### 中心付近の拡大

「6 結果確認」の「中心付近を拡大」で、確認専用の別窓を開きます。画像は左側に可能な限り正方形で表示し、右側に交点一覧、その下のスクロール枠に表示チェックを配置します。左右の境界をドラッグして幅を調整できます。表示範囲と倍率は、全交点・レーザー点・選択方式の推定中心、および交点ラベルが画像領域に収まるよう自動計算します。固定の64×64pxではありません。メイン画像の倍率・位置は変わりません。

- 左ドラッグで移動し、ホイールで現在の表示中心を基準に拡大・縮小します。縮尺リセットアイコンまたはダブルクリックで全点とラベルを収める自動配置へ戻ります。開くボタンを再クリックした場合も自動配置に戻ります。
- 遠方の交点も自動配置の対象です。外れ値を除いて倍率を大きくする処理は行いません。全ラベルを配置できないサイズの場合は案内を表示します。ウィンドウを広げて縮尺リセットを押してください。
- 別窓の表示チェックはメインから独立しています。画像、中心線、レーザー点、交点、交点ラベル、推定中心が初期ONです。点・線の編集はできません。
- 元の画素を補間せずに拡大します。80画面pxのスケールバーに対応する元画像px数と、校正済みならX/Yそれぞれのmm値を表示します。
- 近接ラベルは離して引出線で結び、同じ位置の交点は帯ペアをまとめます。実際の交点は移動しません。表示しきれない点、画像外の点も一覧で座標と選択中心からの距離を確認できます。
- レポートへの拡大図添付・画像ファイル出力は今後の対応です。今回の対象は拡大ウィンドウの表示です。
- 修正・方式変更・明るさ調整は別窓にも反映します。自動配置中はウィンドウサイズ・結果更新に合わせて再配置し、手動でパン・ズームした後は位置と倍率を保持します。別画像への切替や選択方式が計算不能になった場合は閉じます。

## 計算値

円中心から各中心線への垂直距離の最大値を最小にする中心・半径を計算します。最適中心が複数ある場合は、その半径を保ったまま全線への二乗距離和が最小になる中心を選びます。

レーザー偏位は別の値です。成分は「円中心 − レーザー点」で、画像右・下を正とします。X/Yの画素寸法が異なるときは物理座標で円を独立に解き、pxの結果も保持します。画面の円は物理円を画像座標へ変換した形で表示します。

### 交点重心方式（試験的解析）

有効な中心線の全ペアの交点座標を、ペアごとに等しい重みで平均します。同じ座標の交点も重複したまま数えます。画像外・遠方の交点を自動除外しません。

- 重心座標、レーザーから重心への直線距離とX・Y成分、重心から各交点までの距離と最大値を表示します。Xは画像右、Yは下が正です。G/T/AP等の方向対応は未実装です。
- 画像には水色のレーザー点、赤色の重心、白色の交点とレーザーから重心への線を表示します。画像外の交点は一覧にも記載し、表示範囲を自動拡大しません。
- 正規化線の行列式が絶対値1e-12以下の平行・同一直線ペアは計算不能として一覧に記載します。線間角度1度未満のペアには警告します。非有限値の場合は交点重心を計算不能とし、同方式では保存できません。
- 「交点までの最大距離」は最小円半径とは別の値です。**交点重心方式は広がり・レーザー偏位ともに合否判定しません。** 許容値を設定していても適用しません。
- 交点重心はほぼ平行な線の遠方交点に強く影響されます。操作者が交点一覧を確認してください。

## 記録と出力

「記録」で装置・軸・日付を絞り込み、方式と方式別の広がり指標・レーザー偏位を表示します。トレンドは方式・単位別に表示し、最小円半径と重心からの最大交点距離を混在させません。一覧をUTF-8 CSV、選択した1件を日本語A4・1ページPDFへ出力できます。CSVには方式・最小円半径・最大交点距離を別項目で出力します。PDFは1ページ要約で、交点重心方式の交点数・最大距離・警告を含みます。画像・帯別表・個々の交点の詳細は含みません。

SQLiteはQtのアプリデータフォルダにある **`fistar-v1.sqlite`** です。実際の保存先はステータス欄に表示します。既存のプロジェクト内 `fistar.sqlite` は読み書きせず、旧記録の自動移行は行いません。バックアップはアプリ終了後に新DBファイルをコピーしてください。

記録には選択した中心推定方式、両方式の結果と交点ペア情報、保存時の許容値、校正、レーザー点、チャンネル、検出方式・Pylinac版・使用条件・検出点、元の検出線、修正後の線、画像パスとSHA-256、アプリ・解析版を保持します。元画像自体はDBへコピーしません。記録を再度開くには、保存時の元画像が同じ場所・同じ内容で必要です。再開後も、画像と結果を確認して「結果を確認して保存」で新たに保存します。旧記録の装置・中心推定方式・解析チャンネルと保存結果は保持します。輝度以外で解析された旧記録は、表示を輝度固定とし、輝度で再検出するまで新たな保存を許可しません。旧方式の記録も線・結果・旧条件を保持して開きます。中心方式の指定がない旧記録は最小円方式として表示し、交点重心方式を選んだ際に保存済み線から追加計算します。再開時には再検出せず、明示的に再検出した場合のみ新方式に切り替えます。旧条件を新条件へ数値換算しません。

## 検証

```sh
QT_QPA_PLATFORM=offscreen python -m pytest -q
```

検証環境・結果・適用範囲は [検証記録](docs/validation-v1.md)、要件は [要求仕様書](docs/superpowers/specs/2026-10-01-fistar-requirements-specification.md) を参照してください。撮影・照射手順、3D方式、EPID、DICOMは対象外です。

### 設定の保存先

前回の回転軸は、SQLiteと同じフォルダの `fistar-preferences.ini` に保存します。解析記録と別のローカル設定です。表示項目のON/OFFは従来どおり起動中だけ保持します。

### 画面構成

初期ウィンドウは1000×700です。上部に解析・記録・設定タブを配置します。解析は左約2/3・右約1/3とし、左はファイル指定、正方形を保つ画像、画像ツールと解像度設定、操作説明、画像情報の順です。右は解析設定と結果、その下に開閉式の表示項目を配置します。許容値は設定タブから編集します。

解像度設定は枠を設けず画像下のツールアイコンの右側に配置し、「未校正」「TIFFタグ」「入力値」から選びます。入力値はテキスト欄にmm/pxを入力し、X/Y共通の画素寸法として使用します。画像ツールはFiRecの手・リセット・定規アイコンです。定規を選び「校正」を押し、既知長さをmmで入力してから画像上の2点を左クリックすると、既知長さ÷画素間距離からmm/pxを計算して適用します。

### 定規による測定と校正

定規アイコンを選び、画像内の2点を左クリックします。ピンクの端点と線を表示し、画素距離と、解像度設定がある場合はmm距離を示します。X/Y別の解像度がある場合はそれぞれを反映します。測定だけでは解析値や確認状態を変更しません。

「校正」を押すと既知長さの入力欄（mm）が表示されます。長さを入力して2点を指定すると、既知長さ/画素距離でX/Y共通のmm/pxを算出します。2点・既知長さも校正の再現情報として保存します。同じ点、非有限・ゼロ・負の長さは受け付けません。校正待ちの間は検出/保存を止め、「中止」または手のアイコンで元の解像度へ戻せます。

校正ボタンと既知長さの入力欄は定規アイコンの右隣に表示します。メインの結果欄では交点一覧を省略し、「中心付近を拡大」の右側の表で確認します。
